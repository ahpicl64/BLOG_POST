### 2차 스크럼: 발표 피드백과 기술적 고민 (6월 21일)

**주제**: "발표 피드백 / 발표 준비"

1차 발표 후 받은 코치님들의 피드백을 바탕으로 우리는 깊은 기술적 고민에 빠졌습니다. 특히 **아바타 시스템**에 대한 논의가 치열했습니다.

#### 🤔 아바타 구현에 대한 팀의 고민

**코치님들의 핵심 질문:**
- "얼마나 실제 길이/fit에 대응하는지?"
- "사이즈별로 어떻게 처리할 것인지?"

**우리 팀의 초기 아이디어:**
```
초안: 2D로 추출 → 3D로 변환
대안: 정확성을 위해 3D 모델로 시작
```

**기술적 접근 방법:**
- **Cloth 2 tex** 기술 활용 (img → 3D 추출 → 텍스쳐 입힘)
- **CV 기반 기술** 도입 검토

**전제 사항과 제약:**
- 멀쩡한 앞/뒷 사진이 있어야 함
- 정확성 보장이 가능한지에 대한 기술적 확인 필요

#### 💭 팀 내부의 의문점과 해결 과정

**의문점**: "3D로 기술을 변경했을 때, 사이즈별로 반응이 될까?"

**해결 방향**:
- 사이즈를 비율의 크기로 옷 크기를 변경
- 키/옷을 받았을 때, 파라미터 적용하는 방식

**최종 결론**:
- 사람 → 키/몸무게에 대응하는 아바타를 제공
- 옷도 실제 비율에 대응하도록 렌더링

이 회의에서 우리는 단순한 2D 이미지 처리를 넘어서 **3D 아바타 시스템**이라는 야심찬 목표를 설정했습니다. 기술적으로 도전적이었지만, 팀원들은 "해볼 만하다"는 결론에 도달했습니다.
